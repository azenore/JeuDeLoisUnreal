# JeuDeLoisUnreal



Dans ce jeu 1 objectif avoir assez d'argent pour payer ses taxes

Il y a des cases malus, bonus, dialogues, neutre et mini jeu

Le mini jeu est simple il faut clicker sur les panneaux avant le temps impartis, vous gagnez ou perdez de l'argent



A terme j'aimerais que ce jeu ai plus de mécaniques autours des lois et des règles et plus de mini jeux décallés.

J'ai travaillé un début de map en forme de panneau stop, par la suite une map similaire pourrait être implémenté dans Unity
